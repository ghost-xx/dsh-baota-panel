# 宝塔面板

用一个**接口密钥**接管宝塔（bt.cn）Linux 面板，把服务器运维搬进 DSH：侧边栏看状态，智能体直接改面板。

## 它做什么

- **多台面板**：每台面板独立配置地址/密钥/入口/证书策略，可增删、可切换当前面板；工具都带可选 `panel` 参数。
- **侧边栏面板**：在侧边栏面板列表里加一个「宝塔面板」入口，显示 CPU、内存、负载、网络、磁盘、网站、数据库与服务状态，顶部可切换面板。
- **设置页**：`设置 → 宝塔面板` 里维护面板列表（增删改、设为当前），以及「显示到侧边栏」开关。
- **智能体工具**：与侧边栏共用同一套 Host 逻辑。

| 工具 | 能力 |
| --- | --- |
| `bt_panels` | 列出已配置面板 |
| `bt_system` | 系统概览、磁盘、负载、网络、软件栈 |
| `bt_site` | 网站列表、启动、停止、删除、读站点访问日志 |
| `bt_database` | 数据库列表、删除 |
| `bt_file` | 目录浏览、读文件、写文件、建目录、删除 |
| `bt_crontab` | 计划任务列表、新增、删除 |
| `bt_firewall` | 防火墙规则列表、放行端口、关闭端口 |
| `bt_service` | 服务列表、重启 |
| `bt_logs` | 面板操作日志 |
| `bt_config` | 面板增删改、切换当前面板、侧边栏开关 |
| `bt_api` | 兜底：直接调用任意面板 API 动作 |

## 配置要点

1. 面板 →`设置`→`面板设置`→ 打开 **API接口**，复制 **接口密钥**。
2. 同一处的 **IP白名单** 加入运行 DSH 这台机器的公网出口 IP（或 `*`）。未登记时面板返回 `IP校验失败,您的访问IP为[x]`。
3. 面板地址填**根地址含端口**，例如 `https://panel.example.com:4439`；不要把安全入口拼进去。
4. 面板默认自签证书，`verifyTls` 默认关闭。

## 实测边界（宝塔 Linux 面板 13.2.0）

- API 在**根路径**：`/system?action=...`。拼上安全入口会返回「安全入口校验失败」页；入口只在防火墙、面板日志等少数路由里作为 Referer 校验，填到 `securityEntrance` 即可。
- 面板 `is_spider()` 对非浏览器 UA 直接 404，因此客户端固定使用浏览器 UA。
- 网站 / 数据库 / 日志列表走 `/data?action=getData&table=sites|databases|logs`；`/site?action=GetSiteList` 在本版本返回「指定参数无效」。
- 服务列表由 `GetConcifInfo` 推导（webserver / mysql / php）；面板没有对 API 开放的 systemd 列表。
- `/firewall`、`/logs` 在部分版本只服务已登录的浏览器会话；`bt_firewall` 会原样返回面板的报错。
- `GetConcifInfo` 会带出 MySQL root 密码，插件只保留软件栈字段，密码不进入工具结果与前端。
- 读文件单次上限 20 万字符；更大文件用 `bt_api` 分段读。
